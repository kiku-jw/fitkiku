# Contributing

Bug reports and focused pull requests are welcome for the public iOS client.

Before opening an issue:

1. Remove all health values, Health source identifiers, Pair Links,
   credentials, device identifiers, private URLs, and raw logs.
2. State the iOS and Xcode versions, the visible app state, the expected
   outcome, and whether the result came from a simulator or physical iPhone.
3. Keep medical interpretation and unrelated fitness-coaching changes out of
   scope.

For security or privacy reports, follow [SECURITY.md](SECURITY.md) instead of
using a public issue.

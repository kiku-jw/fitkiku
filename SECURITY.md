# Security policy

Please report security or privacy concerns privately to
`support@kikuai.dev` with the subject `FitKiku security`.

Do not open a public issue containing:

- Apple Health values or Health source identifiers;
- Pair Links, pairing codes, bearer credentials, or request headers;
- private server addresses or configuration;
- device identifiers, raw payloads, screenshots with health data, or raw logs.

Include only the app version, iOS version, exact state or error text, expected
outcome, and time rounded to the nearest minute. KikuAI will ask for the
smallest additional detail needed.

FitKiku is in private testing. No public service-level or background-delivery
guarantee is offered.
